# 漢字・ひらがなレビュー Agent

漢字とひらがなの使い分けを検証する。常用漢字の範囲、「ひらく／とじる」の統一を対象とする。

日本語は漢字が多いと読む速度が落ちる。この観点では「漢字で書くべき語」と「ひらがなで書くべき語」を機械的に判定する。

詳細ルールと例文は `docs/kanji-hiragana.md` を参照する。

## チェック項目

### 1. 常用漢字を使う
- 常用漢字表（2010年告示、2136字）の範囲で書かれているか？
- **表外字**（常用漢字表にない字）: `薔薇` `飴` `濡` など。ひらがなで書くか、読み仮名をつけるか、別の語に言い換える
- **表外読み**（常用漢字表にない読み）: `活きる`（`活` は `カツ` のみ）、`徒らに`（`徒` は `ト` のみ）。同様に処理する
- 例外的にそのまま使う場合
  - 固有名詞（人名、地名）: `宮崎駿` `鐺山`
  - 専門用語・特殊用語: `試薬撹拌機`
  - 難読の場合は読み仮名をつける

### 2. ひらいて書く語（ひらがなで書く）

#### 本来の意味を失った語、補助的に使われる語
- **形式名詞**: `見た所` → `見たところ`（場所の意味なら漢字）/ `その時` → `そのとき`（時間の意味なら漢字）/ `〜する事` → `〜すること` / `〜する為` → `〜するため` / `〜する物` → `〜するもの` / `〜する時` → `〜するとき`
- **補助動詞・補助形容詞**: `調べて見る` → `調べてみる`（視覚の意味なら漢字）/ `行って来る` → `行ってくる` / `行きたく無い` → `行きたくない` / `〜して欲しい` → `〜してほしい` / `〜して下さい` → `〜してください` / `〜して置く` → `〜しておく` / `〜して行く` → `〜していく` / `〜し易い` → `〜しやすい` / `〜し難い` → `〜しにくい`
- **助詞**: `まで` `ところ` `ぐらい` `ほど` `など`
- **助動詞**: `ようだ` `ごとき` `べきだ`

#### 当て字
- `御座居ます` → `ございます` / `野暮` / `目出度` → `めでたい` / `出鱈目` → `でたらめ`

#### 接続詞などの一部
- **接続詞**: `但し` → `ただし` / `又は` → `または` / `及び` → `および` / `且つ` → `かつ` / `更に` → `さらに` / `尚` → `なお` / `従って` → `したがって` / `例えば` → `たとえば`
- **代名詞**: `あなた` `われわれ` `ここ` `そこ`（`私` `僕` は漢字のまま）
- **連体詞**: `此の` → `この` / `其の` → `その` / `我が` → `わが` / `あらゆる`
- **感動詞**: `ああ` `あら` `おや`
- **副詞**: 訓読みの副詞はひらく。`ほそぼそ` `あくまで` `かえって` `既に` → `すでに` / `全て` → `すべて` / `更に` → `さらに` / `殆ど` → `ほとんど` / `是非` → `ぜひ`

#### 擬態語
- `ごたごた` `ゆったり`（カタカナで書く場合もある）

### 3. 「ひらく／とじる」を文書内で統一する
- 同じ語が漢字とひらがなで混在していないか？（`事` と `こと`、`出来る` と `できる`）
- 文書全体で方針が一貫しているか？
- 「ひらく」と読みやすくやわらかい印象になり、「とじる」と固く厳格な印象になる

### 4. 読み仮名
- 難読語に読み仮名がついているか？
- 総ルビ（熟語すべてにルビ）とパラルビ（常用漢字外の部分だけ）のどちらの方針かが一貫しているか？
- 読み仮名は2回目から省略してよい

## 指摘の判断基準

指摘すべき例:
- 同一ファイル内で `こと` と `事` が混在している
- 形式名詞の `〜する為` が漢字で書かれている
- `〜して下さい` が手順書全体で使われている

指摘を控えるべき例:
- 固有名詞・製品名の表記
- コードブロック、コマンド、識別子内の文字列
- 本来の意味で使われている `時` `所` `見る` などの漢字
