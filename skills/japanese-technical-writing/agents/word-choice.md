# 語選びレビュー Agent

品詞ごとの語の選び方を検証する。名詞、代名詞・指示語、形容詞・形容動詞、副詞の係り受け、助詞・助動詞を対象とする。

語の選択ミスは、読み手に別の意味を伝えてしまう。この観点では「この語は誰が読んでも同じ意味にとれるか」を判断する。

詳細ルールと例文は `docs/nouns.md`、`docs/pronouns.md`、`docs/adjectives.md`、`docs/adverbs.md`、`docs/particles.md` を参照する。

## チェック項目

### 1. 名詞

- **難しい言葉を避ける**: `措置` → `処置・取扱い` / `牙保` → `周旋・あっせん`
- **一般化していないカタカナ用語を避ける**: `アスピ` → `向上心` / `フィジビリ` → `実験` / `ジャストアイデア` → `思いつき` / `コンセンサス` → `合意`
- **難解な専門用語を避ける**: `RFP` → `提案依頼書`。使う場合は初出時に説明を添える
- **不要な省略を避ける**: `MTG` → `ミーティング` / `MGR` → `マネージャー` / `代引` → `代金引換`
  - ただしチーム内・業界内で定着した略語（API, CI, PR 等）はそのまま使ってよい
- **独自の複合名詞を避ける**: `時間短縮料理術` → `時間が短縮できる料理術`
  - 漢語を 4 つ以上つなげた自作語は分解する

### 2. 代名詞・指示語

- **人称代名詞**: `私` `私たち` を使う場合、誰／どの組織を指すかが文章中に書かれているか？
- **指示代名詞**: `それ` `これ` `その` が何を指すか一意に決まるか？
  - 指示対象が前の段落にある場合は要注意
- 曖昧な場合の解決策は 2 つ
  1. 指示語を崩して名詞を再び記載する: `それを使う` → `最後のカードを使う`
  2. 名詞を補足する: `それを使う` → `そのカードを使う`
- 技術文書では `これ` `それ` が直前の文全体を指すのか特定の語を指すのかが曖昧になりやすい

### 3. 形容詞・形容動詞

- **名詞を修飾できない形容詞**: `多い` `少ない` `近い` は連体用法で使えない
  - `近い駅に行く` → `近くの駅に行く` / `デパートに近い駅に行く`
  - `多いユーザー` → `多くのユーザー`
- **独自の形容動詞を作らない**
  - 形容動詞として一般的でない語: `一目瞭然な場合` → `一目瞭然である場合`
  - 形容動詞を構成する名詞が一般的でない語: `ASAPで向かう` → `できるかぎり急いで向かう`

### 4. 副詞の係り受け（呼応表現）

副詞は文末とペアで使う。ペアが崩れていないかを確認する。

| # | 種類 | 呼応表現 |
|---|---|---|
| 1 | 打ち消し | 決して〜ない、まったく〜ない、全然〜ない |
| 2 | 仮定 | もし〜たら、たとえ〜ても |
| 3 | 推量 | おそらく〜だろう、まさか〜だろう |
| 4 | 疑問 | なぜ〜か、どうして〜か |
| 5 | 願望 | ぜひ〜ほしい（ください、たい）、どうか〜ください |
| 6 | たとえ | まるで〜ようだ、ちょうど〜ようだ |

- 悪い例: `私は明日休みます。なぜなら、母の病院に付き添います。`
- 良い例: `私は明日休みます。なぜなら、母の病院に付き添うからです。`
- そのほか: `決して忘れる` → `決して忘れない` / `もし明日彼が来るから` → `もし明日彼が来たら` / `たとえ嫌われるから` → `たとえ嫌われても` / `娘はまるで太陽だ` → `娘はまるで太陽のようだ`
- 副詞と文末が離れている長文では特に崩れやすい

### 5. 助詞・助動詞

- **起点の「より」は「から」に言い換える**: `東京より参りました` → `東京から参りました`。`より` は比較にだけ使う
- **並列の「と」を省略しない**: `港区と大阪の栄市の比較` → `港区と大阪の栄市との比較`
- **並列の「たり」は連続させる**: `楽しんだり、没頭するのがよい` → `楽しんだり、没頭したりするのがよい`
- **とりたて型の「も」は意図が伝わる場合にだけ使う**: 暗示される内容が読み手に伝わらない `も` は削除する。内容に自信がないときに書き手が無意識に使いがち
- **推量の「う」は「だろう」に言い換える**: `間違いないと言えよう` → `間違いないだろう`。`う` は意思（`遊ぼう`）にだけ使う
- **助詞の重複**: `〜の〜の〜の` と `の` が 3 つ以上連続していないか？
- **「が」の多用**: 逆接でない `が` で文をつないでいないか？（`〜ですが、〜です`）

## 指摘の判断基準

指摘すべき例:
- 指示語の指す対象が 2 通り以上に解釈できる
- `なぜなら` を使いながら文末が `〜からだ` で受けていない
- 説明のない社内略語やカタカナ語が初出で使われている

指摘を控えるべき例:
- 読み手が確実に共有している専門用語（そのドキュメントの前提知識）
- 直前の名詞を指すことが自明な指示語
